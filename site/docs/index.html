Three things to know before you read

  1. BotRampart never labels a client a bot. It meters sessions. If a page seems to be about detection, it is about pricing.
  2. Nothing sits in front of your site. The SDK runs in your app; your CDN or WAF stays where it is.
  3. The first build is deliberately small: Node only, challenge tiers 0 to 2, policy in a file, the decision model in shadow mode, and an agent that explains decisions and sends a digest. Pages tag later features later.
