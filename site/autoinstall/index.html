What Autoinstall does

  • Run

    The reference code, first.

    Your agent clones the repository and runs npm test, npm run bench and the budget engine on Node alone.

  • Price

    Every route gets a price.

    It reads your app's routes, gives each a path class and computes what one session can spend in a day.

  • Plan

    Your stack, mapped.

    Nine frameworks, five places to run, four edges and five clouds: where each part goes, written to one file.

  • Stop

    Nothing changes without you.

    No package installed, nothing created in a cloud account, no line of your app's code changed.

What your agent does

Five steps. Each one runs today.

  1. 01

    Tests and benchmark

    Clones the repository and runs npm test and npm run bench: signed-cookie checks in about 2 µs each.

  2. 02

    Budget engine

    Runs the quickstart's ten-line script and checks its four lines of output.

  3. 03

    Route prices

    Writes botrampart/path-prices.md and the daily ceiling for your prices.

  4. 04

    Install plan

    Writes botrampart/INSTALL-PLAN.md: the middleware, the script tag, your edge, Core and the bucket, each with its docs page.

  5. 05

    Report and stop

    Reports the numbers and the two files, and changes nothing else.
